# 로드맵

이 초안에 **없는 것**을 솔직하게 적고, 다음에 무엇을 할지 정리한 문서입니다.
지시하실 때 이 목록을 기준으로 골라주시면 됩니다.

## 지금 동작하는 것

- 이메일/비밀번호 인증, 기기별 세션, 토큰 회전, 기기 단위 폐기
- 워크스페이스, 역할(owner/admin/member/guest), 초대
- 공개·비공개 채널, 1:1 및 그룹 DM, 채널 둘러보기(사이드바 진입점)
- 채널 설정 UI: 이름·주제 수정, 구성원 추가/제거·관리자 위임(관리자), 보관, 나가기;
  구성원 변동은 시스템 라인으로 전사록에 남음
- 메시지: 마크다운(표·제목·번호목록·체크리스트·코드 복사 포함), 한글 이름 멘션,
  1단 스레드(채널 안 읽음 비포함), 반응, 고정, 수정·삭제, 공유 시 원문 permalink
- 파일: 2단계 업로드(로컬/S3, 진행률 표시), 첨부, 클립보드 이미지 붙여넣기, 파일
  모아보기 화면(종류·내 파일 필터, 검색, 공유된 메시지로 점프), 라이트박스(이전/다음·
  원본 크기), 파일명 가시성 = 다운로드 권한(내 업로드 또는 내가 속한 채널의 첨부)
- 활동 화면: 내가 낀 스레드(새 답글 수)와 나를 부른 멘션 모아보기
- 이모지 피커(한국어 검색, 최근 사용) + `:tada:` 단축코드 자동완성
- 프로필 사진 업로드(브라우저에서 256px 정사각 리사이즈, 비인증 캐시 URL)
- 환경설정: 워크스페이스 구성원 목록·역할 변경·내보내기, 로그인 기기 목록·개별 종료
- 링크 앱: 구성원 누구나 추가, 추가 전 서버 프로브(X-Frame-Options/CSP, SSRF 가드)로
  임베드 거부를 미리 알림 → 새 탭 타일, 이름 변경, 추가/변경/삭제의 실시간 반영
- 읽음 상태, 안 읽음·멘션 카운터, 알림 수준, 음소거
- 실시간: WebSocket 게이트웨이, 타이핑, 프레즌스, seq 갭 감지, 재연결
- 미니앱: 매니페스트 등록, 설치, 스코프, 브릿지 API, 샌드박스 패널, KV 저장소, 봇 계정
- 링크 앱: URL 하나로 팀의 웹 도구를 도크에 추가 → 메인 패널 iframe.
  브릿지 토큰 발급이 구조적으로 불가(`has_panel`=false), 스코프 금지, http(s)만
- 통합 검색 (⌘K): 채널·사람·앱·메시지·파일 (파일은 Enter 로 바로 다운로드)
- 오프라인: 로컬 SQLite 캐시, 아웃박스, 멱등 재전송
- 저장소: Postgres 에서 `messages` 는 월별 파티션(ULID 범위 = 시간)으로 운영되고 매일 작업자가
  다음 달 파티션을 미리 만듭니다. 오래된 달은 `DROP TABLE` 한 번으로 정리됩니다 (`GET /admin/partitions`)
- 운영: 감사 로그(관리자 행위 추적·CSV), 보관 정책(워크스페이스·채널별 보존 일수, 매시간 정리),
  첨부 바이러스 검사(clamd INSTREAM, 격리·알림), Prometheus `/metrics`, 작업자 프레임워크(리더 락),
  Redis 공유 레이트 리밋, 썸네일 생성, Range 스트리밍·미디어 토큰(동영상 인라인 재생),
  Postgres 전문검색, 부하 테스트 스크립트(`backend/scripts/loadtest.py`)
- 알림: 방해 금지 시간·요일, 일시 중지(30분~내일까지, `/dnd`), `@here`(접속 중인 사람만)와
  `@channel` 구분, 멘션 배지와 안 읽음 수 병기
- 나중에 보기: 메시지 저장·메모·리마인더(프리셋/직접 지정, `/remind`), 사이드바 '나중에', 완료/재열기
- 초대 이메일 자동 발송(SMTP 설정 시) + 재발송(토큰 교체), 첫 진입 안내 카드, 사이드바 섹션(채널 묶기·접기),
  링크 카드(og 태그 언펄, SSRF 가드, 캐시)
- 앱 플랫폼: 슬래시 커맨드(내장 6종 + 앱 커맨드, HMAC 서명·response_url), 이벤트 웹훅(재시도·전달 기록),
  인터랙티브 블록(버튼·선택 → 앱 → 메시지 교체/개인 응답), 앱 홈 탭, 앱 심사(초안 → 심사 대기 → 게시/반려,
  서비스 관리자), 개발자 콘솔(매니페스트 등록·수정, 서명 비밀, API 토큰, 웹훅 테스트·전달 기록)
- **에이전트 패널**: 세 번째 도킹 시트, 사용자가 연결하는 프로바이더(키는 OS 키체인),
  Rust 정책 게이트 + 액션별 승인 + 해시 체인 감사 로그, 채널 읽기·검색·게시 도구,
  `host.exec`/`host.read_file`/`host.write_file`, 아티팩트(핸들+프리뷰). 자세한 것과 **없는 것**은
  [AGENT.md](AGENT.md) 에 있습니다.

## 1순위 — 상용 배포 전에 반드시

| 항목 | 상태 |
| --- | --- |
| **SSO (SAML / OIDC)** | 사용자가 직접 구현 예정. 그동안은 이메일/비밀번호 + `LLACK_REQUIRE_INVITE=true` 초대 필수 가입으로 운영합니다. |
| **자동 업데이트** | 데스크톱 앱 갱신 수단(Tauri updater + 서명 키)은 빌드 환경(macOS/Windows)이 있어야 붙일 수 있어 남겨둡니다. 파일럿은 웹 모드를 권합니다. |

레이트 리밋(Redis 공유)·감사 로그·바이러스 검사·보관 정책·부하 테스트 스크립트는 구현되어 "지금 동작하는 것"으로 올라갔습니다.

## 2순위 — 일상 사용성

2순위 목록은 전부 구현되었습니다. 다음 후보:

- **채널 섹션 이름 변경·순서**: 섹션은 있지만 이름 바꾸기·드래그 정렬은 없습니다

| **3등급 네이티브 다이얼로그** | 지금은 `host.exec` 도 인앱 카드입니다. JS 가 위조하거나 스크립트로 클릭할 수 없는 OS 다이얼로그로 올려야 합니다. |

| **메모리 · 스킬** | 세션 간에 기억하는 것이 없습니다. |
| **화면·마우스 제어** | 스크린샷도 클릭도 없습니다. 정책에 2등급 자리만 비어 있습니다. |

## 4순위 — 규모와 운영

- **외부 검색 색인**: Postgres 전문검색은 붙었습니다. 그 이상은 외부 색인(Meilisearch 등)
- **트레이싱**: 메트릭(Prometheus)은 있고 분산 트레이싱(OpenTelemetry)은 없습니다

## 알려진 한계

의도적으로 남긴 것들입니다. 필요해지면 바꾸면 됩니다.

- **스레드는 1단**입니다. 답글의 답글은 같은 스레드에 들어갑니다 (Slack 과 동일).
- **검색은 SQLite 에서는 LIKE 스캔**, Postgres 에서는 전문검색(GIN)입니다.
- **개발 기본값은 SQLite** 입니다. 프로덕션은 반드시 Postgres 를 쓰세요
  (동시 쓰기 처리량이 다릅니다).
- **Redis 없이 워커 2개 이상은 불가**합니다. 이벤트·레이트 리밋·작업자 리더 락이 워커 간에
  공유되지 않습니다. 단일 워커로는 완전히 정확합니다.
- **`--forwarded-allow-ips *`** 가 개발 기본값입니다. 프로덕션에서는 프록시 IP 로
  좁혀야 합니다 — 그러지 않으면 클라이언트가 X-Forwarded-For 를 위조할 수 있습니다.
- **로컬 캐시는 암호화되지 않습니다.** 메시지 본문이 사용자 데이터 디렉터리의
  SQLite 에 평문으로 있습니다. 디스크 암호화를 전제하고 있습니다.
- **Tauri 셸은 이 환경에서 빌드되지 않습니다** (webkit2gtk 없음).
  macOS/Windows/Ubuntu 에서 빌드하세요.
